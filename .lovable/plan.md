## Screenshots of the current site for Claude Design

Capture clear pictures of every main page as it looks now, so you can hand them to Claude Design for new layout ideas.

### What you'll get
- Pictures of each page on a **computer** (1440px wide) and a **phone** (390px wide).
- Long pages are split into numbered sections (top to bottom), so nothing is cropped or tiny.
- The cookie pop-up is closed before capturing, so it doesn't cover the pages.
- Everything is put into one ZIP in your Files, organised by page, plus a short note listing the brand rules (cream #FAF3ED, black text, sage #A3C1AD, Libre Baskerville headings, lowercase "balance", no pink, real studio photos) to paste into Claude Design with the pictures.

### Pages included
Home, Our Studios, Class Types, Pricing, Membership Offers, Schedule, Events, one studio page (Limerick), Shop, Careers, Education, About, Thank-you.

### Bringing designs back
When Claude Design gives you something you like, send its pictures or code here and I'll rebuild it in preview using your real prices, links and booking timetables, so nothing goes live until you publish.

### Technical details
- Playwright against the local preview, cookie consent pre-dismissed via the Reject choice.
- Booking timetables (Momence) may load slowly. I'll wait for them, and if one doesn't load I'll mark it in the note.
- Output: `/mnt/documents/balance-site-screenshots.zip` (built in /tmp first). No site code changes.
